# ARCHIVE//HUD

A dark sci-fi heads-up display built with Lucee 6 (CFML) and MySQL 8, with two switchable variants:

- **7 Sectors**: Jonathan's Drive archive map, rolled up by sector and top folder. No file names are stored or published.
- **3 Companies**: an independent fan/preservation dashboard for the Wikimedia Foundation, Mozilla, and the Linux Foundation.
  *Independent fan dashboard. Not affiliated with or endorsed by Wikimedia, Mozilla, or the Linux Foundation.* No logos are used.

It also has a read-only public JSON feed (`/api/feed.cfm`) and a Blogger widget that renders it.

Screenshots are in `docs/`.

## Deploy on an Oracle Cloud Always Free VM (Ubuntu, ARM)

### 1. Create the VM (Oracle console)

1. Compute → Instances → **Create instance**.
2. Image: **Canonical Ubuntu 24.04** (or 22.04). Shape: **VM.Standard.A1.Flex** (Ampere ARM, Always Free eligible), e.g. 1 OCPU / 6 GB RAM is plenty.
3. Add your SSH public key. Create.
4. Note the **public IP**.

### 2. Open ports 80 and 443

Two layers have to allow the traffic.

**a) Oracle network (Security List or NSG).** Networking → Virtual Cloud Networks → your VCN → Security Lists → Default → **Add Ingress Rules**:

| Source CIDR | Protocol | Dest. port |
|---|---|---|
| 0.0.0.0/0 | TCP | 80 |
| 0.0.0.0/0 | TCP | 443 |
| 0.0.0.0/0 | UDP | 443 (optional, HTTP/3) |

**b) The VM's own firewall.** Oracle's Ubuntu images ship with iptables rules that reject everything except SSH:

```bash
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80  -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p udp --dport 443 -j ACCEPT
sudo netfilter-persistent save
```

### 3. Install Docker (official repository)

```bash
ssh ubuntu@YOUR_VM_IP
sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER   # log out and back in afterwards
```

### 4. Upload and configure

From your own computer:

```bash
scp hud.zip ubuntu@YOUR_VM_IP:~
```

On the VM:

```bash
sudo apt-get install -y unzip && unzip hud.zip && cd hud
cp .env.example .env
# Generate a value for each password (run once per password):
openssl rand -base64 33 | tr -d '/+=' | cut -c1-32
nano .env            # replace every CHANGE_ME, set HUD_ADMIN_PASSWORD (12+ chars) if you want /admin
chmod 600 .env
```

Password rules: 16-128 characters of `A-Z a-z 0-9 _ . @ % + = -` (`db/init/03_users.sh` refuses anything else so the SQL stays injection-proof).

### 5. Start it (HTTP only)

```bash
docker compose up -d
docker compose logs -f          # first start: MySQL init ~30-60 s, Lucee installs the MySQL driver
```

Open `http://YOUR_VM_IP/`. The feed is at `http://YOUR_VM_IP/api/feed.cfm?variant=sectors`.

### 6. Optional: HTTPS with Caddy (recommended)

You need a domain name whose DNS **A record** points at the VM's public IP.

Edit `.env`:

```ini
HUD_BIND=127.0.0.1
HUD_HTTP_PORT=8080
HUD_DOMAIN=hud.yourdomain.com
HUD_ACME_EMAIL=you@yourdomain.com
HUD_COOKIE_SECURE=true
HUD_TRUST_PROXY=true
HUD_HSTS=true
```

Then:

```bash
docker compose --profile https up -d
```

Caddy gets and renews a Let's Encrypt certificate on its own, serves 80/443, and proxies to Lucee. The app itself is then only on `127.0.0.1:8080` on the VM.

A Blogger widget on an `https://` blog can't fetch an `http://` feed (browsers block mixed content), so the widget needs HTTPS.

## Blogger widget

1. Open `blogger-widget.html` and set `HUD_API_BASE` to your HTTPS origin, e.g. `https://hud.yourdomain.com` (no trailing slash).
2. Blogger → Layout → Add a Gadget → **HTML/JavaScript** → paste the whole file → Save.
3. CORS allows only `https://<anything>.blogspot.com`. If the blog uses a custom domain, add it, exactly, to `HUD_CORS_EXTRA_ORIGINS` in `.env` (e.g. `https://www.yourblog.com`) and run `docker compose up -d` again.

The widget builds every element with `createElement` + `textContent`, never parses HTML from the feed, and only links to `https://` URLs.

## Admin

- `https://your-domain/admin/` → password from `HUD_ADMIN_PASSWORD`. Leave it empty and admin is off.
- You can edit taglines, missions, volunteer text, and preservation notes; add or remove projects, links, and folder rollups; and post or delete status-ticker lines.
- Every form carries a CSRF token. Login is limited to 5 attempts per IP per 15 minutes. The session cookie is HttpOnly + SameSite=Strict (+ Secure with `HUD_COOKIE_SECURE=true`) and lasts 30 minutes.
- Only `https://` links are accepted.
- Use admin over HTTPS only.

## Security model

| Area | What's done |
|---|---|
| SQL | Every query uses `<cfqueryparam>`. JDBC has `allowMultiQueries=false` and `allowLoadLocalInfile=false`. |
| DB users | `hud_ro` (public HUD + API) can only `SELECT` four `v_public_*` views. `hud_rw` (admin) has row DML on the four tables and no DDL. Root is used only by the MySQL container's init. MySQL has no published port. |
| API | GET/HEAD/OPTIONS only, a whitelisted variant, and whitelisted fields copied into a fresh struct. JSON is escaped for `< > & U+2028 U+2029` and served as `application/json` with `nosniff`. |
| CORS | `Access-Control-Allow-Origin` is echoed only for `https://[a-z0-9-]+.blogspot.com`, plus explicit extras. `Vary: Origin`. No credentials. |
| Writes | No public write endpoints. Admin writes are POST-only and need both a session and a CSRF token. |
| Headers | CSP (`default-src 'none'`, `script-src 'none'`, self styles only), `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, Referrer-Policy, Permissions-Policy, COOP, and optional HSTS. Bar widths use CSS classes, so the CSP needs no `unsafe-inline`. |
| Output | All HTML output is `encodeForHTML` / `encodeForHTMLAttribute`. |
| Lucee | `LUCEE_ADMIN_ENABLED=false` turns off `/lucee/admin`, and Caddy blocks `/lucee/*` too. `lib/` and `includes/` return 404. Remote CFC calls are refused. Errors show a generic message and are logged to `hud.log`. |
| Cookies | The public pages and API set no cookies. Sessions exist only under `/admin`. |

### Rate limiting

- **In app:** `/api/feed.cfm` allows `HUD_API_RATE_PER_MIN` requests (default 60) per client IP per minute, then returns `429` with `Retry-After: 60`. The counter lives in memory, per Lucee instance, and resets on restart. That's fine for one small VM.
- **Client IP:** behind Caddy, set `HUD_TRUST_PROXY=true` so the limiter reads `X-Forwarded-For`. Without Caddy, keep it `false` so clients can't spoof their IP.
- **Caching:** feed responses send `Cache-Control: public, max-age=60`, and queries are cached for 30 s, so Blogger traffic barely touches MySQL.
- **More:** stock Caddy has no rate limiter. For heavier abuse, use a Caddy build with the `caddy-ratelimit` module, or put Cloudflare (free plan) in front of the domain.

## Updating data

- **New Drive map:** run
  `python3 tools/build_seed.py --totals ../sector_totals.json --csv ../SEC_SHINRADOOM_SECTOR_MAP.csv --out db/init/02_seed.sql --preview tools/seed_preview.json`.
  The init scripts only run on an **empty** DB volume. To reload, either:
  - wipe and recreate, which **destroys admin edits**: `docker compose down -v && docker compose up -d`, or
  - truncate the four tables yourself and pipe the new `02_seed.sql` in with `docker compose exec -T db mysql -uroot -p"$MYSQL_ROOT_PASSWORD" hud < db/init/02_seed.sql`.
- **Sizes:** `sector_totals.json` sizes are in GB, despite the "MB" label: each one equals the CSV's summed `Size MB` ÷ 1000. The HUD stores and shows exact MB from the CSV. The raw JSON value is kept in `sectors_or_orgs.reported_size`.
- **Sensitive names:** top folders whose names look sensitive (ID, license, medical, tax, bank, resume, …) are relabelled "Restricted folder". No file names are ever seeded.

## Backups

```bash
docker compose exec -T db sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" --single-transaction hud' > hud-backup.sql
```

## Ads (AdSense)

This app's CSP blocks all third-party scripts, so AdSense can't run on the HUD pages as shipped. The simple route is to run ads on the **Blogger** blog, which has built-in AdSense support, and use the widget there. Putting ads on the HUD itself would mean loosening the CSP for Google's ad domains, plus adding an `ads.txt` and a privacy policy page.
